# ዓሚኤል በገና | Amiele Begena 🎵

An e-commerce website for authentic handcrafted 
Ethiopian musical instruments including Begena, 
Krar, Masinko, Kebero and more.

## 🌍 Live Site
https://amielestore-web.vercel.app

## ✨ Features
- Multi-currency support (ETB, USD, EUR)
- Shopping cart system
- WhatsApp order integration
- Product sound player
- Customer review system
- Language toggle (English / Amharic)
- Lightbox photo gallery
- Scroll animations
- Google Analytics
- SEO optimized
- Fully responsive (mobile & desktop)

## 🛠️ Built With
- HTML5
- CSS3
- Vanilla JavaScript
- Deployed on Vercel
